┌───────────────────────────────────────────────────────────────────────────┐
│ TECHNICAL ARCHITECTURE                                                    │
└───────────────────────────────────────────────────────────────────────────┘

User Input (Cmd/Ctrl+K)
    │
    ├─→ Quick Actions (Static)
    │   ├─ Analizar PDF → PDF Upload Dialog
    │   ├─ Nueva comparación → router.push(/{locale}/workspace/cases/new?kind=comparison)
    │   ├─ Crear propuesta → router.push(/{locale}/workspace/cases/new?kind=proposal)
    │   ├─ Nuevo cliente → router.push(/{locale}/workspace/clients/new)
    │   └─ Abrir Agente → toggleRight() [Zustand state]
    │
    └─→ Recent Items (Lazy Loaded)
        │
        └─→ GET /api/workspace/recents
            │
            ├─→ getRecentPolicies(orgId)
            └─→ getRecentProposals(orgId)
