6. REFERENCIAS RÁPIDAS
================================================================================

6.1. COMANDOS ÚTILES
--------------------

Aplicar todas las migraciones:
-------------------------------
for file in supabase/migrations/*.sql; do 
    npx prisma db execute --file "$file" --schema prisma/schema.prisma; 
done

Sincronizar Prisma con BD:
---------------------------
npx prisma db pull && npx prisma generate

Ver estructura de base de datos:
---------------------------------
npx prisma studio

Generar cliente de Prisma:
---------------------------
npx prisma generate

Verificar conexión a BD:
-------------------------
npx prisma db push --accept-data-loss=false

Ver migraciones aplicadas:
---------------------------
SELECT * FROM schema_migrations;

Ver logs de auditoría recientes:
---------------------------------
SELECT * FROM audit_log ORDER BY created_at DESC LIMIT 50;

Ver estadísticas de organización:
----------------------------------
SELECT public.get_case_stats('org-uuid-here');
SELECT public.get_artifact_stats('org-uuid-here');

6.3. TABLAS PRINCIPALES
------------------------

Multi-tenancy:
--------------
- organizations: Entidad raíz
- org_members: Membresías de usuarios
- clients: Clientes con PII cifrada

Core business:
--------------
- cases: Casos de análisis
- artifacts: Documentos y metadatos
- audit_log: Registro de auditoría

Autenticación (Supabase):
--------------------------
- auth.users: Usuarios del sistema
- public.profiles: Perfiles extendidos

---

6.4. FUNCIONES IMPORTANTES
---------------------------

Cifrado:
--------
- encrypt_pii(text) → bytea
- decrypt_pii(bytea) → text

RLS:
----
- is_org_member(org_uuid, user_uuid) → boolean
- get_user_role(org_uuid, user_uuid) → text
- is_org_admin(org_uuid, user_uuid) → boolean

Storage:
--------
- generate_storage_path(org_uuid, file_name, bucket) → text
- get_secure_download_url(file_path, bucket, expires) → text
- cleanup_temp_files() → void

Estadísticas:
-------------
- get_case_stats(org_uuid) → jsonb
- get_artifact_stats(org_uuid) → jsonb

---

6.5. PATRONES DE CÓDIGO COMUNES
--------------------------------

Crear caso con RLS:
-------------------
const newCase = await prisma.case.create({
  data: {
    orgId: user.orgId,
    clientRef: 'CLI-001',
    status: 'draft'
  }
});

Cifrar datos de cliente:
-------------------------
await prisma.$executeRaw`
  INSERT INTO clients (org_id, name_enc, email_enc)
  VALUES (
    ${orgId}::uuid,
    encrypt_pii(${name}),
    encrypt_pii(${email})
  )
`;

Upload de archivo:
------------------
const filePath = await supabase.rpc('generate_storage_path', {
  org_uuid: orgId,
  file_name: file.name
});

await supabase.storage.from('artifacts').upload(filePath, file);

Obtener usuario actual:
------------------------
import { createServerSupabase } from '@/lib/supabase/server';

const supabase = await createServerSupabase();
const { data: { user } } = await supabase.auth.getUser();

7. GLOSARIO
================================================================================

RLS: Row Level Security - Seguridad a nivel de fila en PostgreSQL
PII: Personally Identifiable Information - Información personal identificable
PGP: Pretty Good Privacy - Sistema de cifrado
UUID: Universally Unique Identifier - Identificador único universal
JSONB: JSON Binary - Formato JSON optimizado de PostgreSQL
FK: Foreign Key - Clave foránea
CASCADE: Eliminación en cascada de registros relacionados
SECURITY DEFINER: Función que se ejecuta con privilegios del dueño
bytea: Tipo de datos binario de PostgreSQL
inet: Tipo de datos para direcciones IP de PostgreSQL
